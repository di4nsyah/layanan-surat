Kerjakan FASE 1 saja: HTML + CSS bare-bones untuk halaman WARGA. Halaman admin ditunda.

Larangan Fase 1: tidak boleh ada JavaScript (tanpa tag <script>), tidak ada styling dekoratif (warna, gradient, shadow, border-radius, font eksternal), tidak ada framework/CDN.

Buat struktur persis ini:
layanan-surat/
├─ index.html
├─ css/style.css
└─ warga/ daftar.html, login.html, dashboard.html, ajukan.html, lacak.html

Ketentuan umum:
- HTML5 semantik (header, nav, main, section, footer), lang="id", meta viewport, satu file css yang sama untuk semua halaman.
- Setiap input punya <label for>. Pakai atribut HTML untuk validasi (required, pattern, minlength, type, accept).
- CSS hanya untuk keterbacaan dan tata letak dasar: font sans-serif, max-width sekitar 40rem, form satu kolom, tabel dengan border, tabel dibungkus div overflow-x:auto agar aman di HP.
- Bahasa tombol jelas dan aktif (mis. "Buat akun", "Kirim pengajuan").

Isi tiap halaman:
1. index.html: judul, penjelasan singkat, daftar 4 jenis surat, 4 langkah cara kerja, link ke daftar/masuk.
2. daftar.html: nama lengkap, NIK (16 angka, pattern), no HP, email, kata sandi + ulangi, checkbox persetujuan.
3. login.html: email, kata sandi, link ke daftar.
4. dashboard.html: sapaan, link "Ajukan surat baru", tabel pengajuan dummy (No., Jenis, Tanggal, Status, Aksi) dengan 3 baris berstatus Diverifikasi, Selesai, Ditolak.
5. ajukan.html: form 5 langkah memakai fieldset+legend: (1) pilih jenis surat (radio), (2) data pemohon, (3) data sesuai jenis: 4 fieldset terpisah dengan field masing-masing jenis (pengantar: instansi tujuan, keperluan; domisili: lama tinggal, keperluan; SKTM: penghasilan, tanggungan, keperluan; usaha: nama, jenis, alamat, lama usaha), (4) unggah berkas: KTP dan KK wajib, pendukung opsional, accept .jpg,.jpeg,.png,.pdf, tulis "maksimal 2 MB", (5) checkbox konfirmasi + tombol kirim.
6. lacak.html: ringkasan pengajuan (dl), tabel riwayat status dummy (Waktu, Status, Keterangan), daftar berkas, bagian "Hasil surat" berisi teks bahwa unduhan muncul setelah disetujui.

Nav antar halaman harus saling terhubung dan tidak ada link mati.
